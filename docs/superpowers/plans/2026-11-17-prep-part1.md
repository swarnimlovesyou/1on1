# Prep Part 1 (area, guides, CS fundamentals) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the Prep area with the guide format, server-graded guide quizzes, per-track progress, and 30 original CS
fundamentals guides.

**Architecture:**
- Guides are generated into `content.json` under a new `guides` key, seeded as `guide` documents, and served by
  `PrepController`.
- `ChallengeService.find` also searches guides, so the existing attempts endpoint grades their quizzes.
- React pages under `/prep` reuse `ChallengeCard` and compute progress from the attempts the progress summary already
  returns.

**Tech Stack:** Python 3 content scripts, Spring Boot / Java 21, React, Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-11-17-prep-design.md`

## Global Constraints

- **Original content only.** Nothing copied from DSABuddy or other sites. No claim of exam or company coverage.
- **The DSA catalogue is untouched:** 33 lessons and 24 concepts. Guide attempts never enter the concept map, review,
  plans or the `/progress` lesson count.
- **Guide shape:** `{id:"guide-<track>-<slug>", kind:"guide", track, subject?, title, order, summary, sections:[{title,
  text}] (3–5), keyPoints:[str] (3–6), challenges:[5 × prediction]}`.
- **Each challenge:** `{id:"challenge-<guide slug>-q<n>", kind:"prediction", title, prompt, options (3–4), answer
  (index), explanation, hint}`.
- **Tracks:**

  | Id | Title |
  | --- | --- |
  | `aptitude` | Aptitude |
  | `reasoning` | Reasoning |
  | `puzzles` | Puzzles |
  | `cs-fundamentals` | CS fundamentals |
  | `system-design` | System design |

  CS fundamentals guides carry `subject`, one of `OOP`, `DBMS`, `Operating systems`, `Computer networks` or `SQL`.
- **Passing:** a guide is "passed" when each of its 5 challenges has a correct attempt.
- **No schema change.** A document flagged `edited` is never overwritten by seeding.
- **Textbook UI** tokens and `.prose`; works at 390 px; quizzes are accessible through `ChallengeCard`.

## Review Focus

1. **A guide quiz answered by a guest:** graded with feedback, nothing stored, no error. Pinned in Task 1.
2. **A wrong answer, then a right one:** the guide counts as passed only once all 5 have a correct attempt. Pinned in
   Task 3.
3. **A guide id on DSA endpoints** (learning map, plans): ignored, and DSA counts unchanged. Pinned in Task 1.
4. **The public guide response:** must not expose answers. Pinned in Task 1.
5. **A long subject guide at 390 px:** no sideways scroll. Pinned in Task 3's spec.
