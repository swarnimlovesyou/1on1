# Prep part 2: aptitude and reasoning Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Aptitude (8 topics) and reasoning (5 topics) guides, each with a 5-question quiz, plus unlimited server-generated drills per topic and a drill page.

**Architecture:** `DrillService` holds 13 pure generators `(Random) -> Drill` and grades by regenerating from `(topic, seed)`; `DrillController` serves `next` and `answer` and logs a daily `drill` event for signed-in learners. Guides reuse part 1's format with a `drill` field; the track and guide pages link to `/prep/drill/:topic`.

**Tech Stack:** Spring Boot 4 / Java 21, `java.util.Random`, React + react-query, Vitest, Playwright, Python content scripts.

**Spec:** `docs/superpowers/specs/2026-11-17-prep-design.md` (sections Goals, Generated drills, Pages; order of work item 2).

## Global Constraints

- Additive only: no schema change, no change to the DSA lessons, the concept map, the 24/33 counts or review.
- Drills: `GET /api/v1/drills/{topic}/next?seed=` → `{topic, seed, prompt, options?, unit?}`; `POST /api/v1/drills/{topic}/answer {seed, answer}` → `{correct, expected, explanation}`. The answer never reaches the client before submit.
- Generators are pure functions with integer answers (or an option/text answer). A signed-in answer calls `progress.record(user, "drill", topic)`; no attempt rows. Drills are public.
- Content is original, checked by `check_prep.py`, and fact-checked by a separate pass before merge. No exam or company coverage claims.
- Textbook UI tokens; accessible controls; works at 390 px.

## Review Focus

1. **An answer typed as `" 1,200 "`, `"40.0"` or lowercase `"ecv"`:** graded by value (numbers) or case-insensitively (text), not rejected on format. Pinned in Task 2.
2. **A bad request (`seed=abc`, `seed=-1`, `seed=99999999999`, unknown topic):** 400 or 404 with a sentence, never 500. Pinned in Task 2.
3. **A guest drilling:** graded, nothing recorded, no sign-in prompt. Pinned in Task 2 (service) and Task 4 (browser, as a guest).
4. **The same seed twice, including after a restart:** the same question. Pinned in Task 2.
5. **A long syllogism prompt at 390 px:** wraps, no sideways scroll. Pinned in Task 4.

### Task 2: DrillService and its endpoints

**Files:**
- Create: `backend/src/main/java/com/oneonone/DrillService.java`, `DrillController.java`
- Modify: `SecurityConfig.java` (permit `/api/v1/drills/**`)
- Test: `backend/src/test/java/com/oneonone/DrillTest.java`

**Interfaces:**
- Produces:
  - `record Drill(String prompt, String answer, String explanation, List<String> options, String unit)` (options and unit nullable).
  - `DrillService.TOPICS`: `Map<String, String>` topic id → track, insertion-ordered: aptitude `percentages, profit-loss, ratio-proportion, averages, interest, time-work, speed-distance, number-systems`; reasoning `number-series, letter-series, coding-decoding, directions, syllogisms`.
  - `Drill generate(String topic, int seed)` — `new Random(seed)`; unknown topic → 404 "That drill topic doesn't exist."
  - `boolean matches(String expected, String given)` — trim; drop commas between digits; if `expected` parses as a number compare `BigDecimal.compareTo == 0`; else `equalsIgnoreCase`.
  - `GET /api/v1/drills/{topic}/next?seed=` → `{topic, seed, prompt, options?, unit?}`; seed absent → random in `[0, Integer.MAX_VALUE]`; non-integer or out of that range → 400 "The seed must be a whole number from 0 to 2147483647."
  - `POST /api/v1/drills/{topic}/answer {seed, answer}` → `{correct, expected, explanation}`; blank answer → 400; signed-in → `progress.record(user, "drill", topic)` (already one event per user, kind, source and day).

Generators (all answers integers unless stated; pick inputs so they are):

| Topic | Question | Answer |
| --- | --- | --- |
| percentages | "What is p% of n?" or "x is what percent of y?" | number |
| profit-loss | selling price from cost and profit/loss %, or profit % from cost and selling price | number, unit ₹ / % |
| ratio-proportion | split T in ratio a:b (or a:b:c), give one named share | number |
| averages | average of n listed numbers, or the number that moves an average of n from A to B | number |
| interest | simple interest P,R,T; or compound interest for 2 years, R ∈ {10, 20}, P a multiple of 100 | number |
| time-work | A alone a days, B alone b days, together? from integer triples (3,6,2) (4,12,3) (6,12,4) (10,15,6) (12,24,8) (20,30,12) (12,36,9) × m ∈ 1..3 | days |
| speed-distance | train of length L at v km/h (v a multiple of 18) passes a pole: seconds | seconds |
| number-systems | LCM or HCF of two numbers built from small prime factors | number |
| number-series | arithmetic, geometric, n²+k, or alternating differences; 5 terms shown, next term | number |
| letter-series | letters stepping by k (wrapping Z→A), next letter | letter |
| coding-decoding | "If WORD is coded as SHIFTED, how is WORD2 coded?" shift ±1..5 over a fixed list of 3–5-letter common words | text |
| directions | 3–4 axis moves whose net displacement is (3,4,5)·m or one-axis; straight-line distance from start | metres |
| syllogisms | one of the templates below with random plural nouns; options `Only I follows`, `Only II follows`, `Both follow`, `Neither follows` | option |

Syllogism templates (premises; conclusion I; conclusion II; answer):
1. All A are B. All B are C. — All A are C. — Some C are A. — Both follow
2. All A are B. Some B are C. — Some A are C. — Some C are B. — Only II follows
3. No A is B. All C are B. — No C is A. — Some A are C. — Only I follows
4. Some A are B. All B are C. — Some A are C. — All C are A. — Only I follows
5. All A are B. No B is C. — No A is C. — Some B are A. — Both follow
6. Some A are B. No B is C. — Some A are not C. — No A is C. — Only I follows
7. All A are B. All C are B. — All A are C. — Some A are C. — Neither follows
