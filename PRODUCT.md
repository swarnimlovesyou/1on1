# 1on1
<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
Confirmed: React and TypeScript frontend, Java Spring Boot backend, PostgreSQL production storage. Gemini replaces the initially proposed OpenAI integration at the user's request.

## Users
Students learning DSA, individually and in small cohorts, with an academic Advanced Algorithms project as the implementation context.

## Product Purpose
An interactive study notebook connects visual understanding, prediction checkpoints, coding practice, revision, and progress tracking. A complete student can learn, experiment, solve, and resume across sessions.

## Positioning
Visual learning first. AI adapts deterministic Java-generated algorithm traces and supplies contextual help. It never grades code or invents execution states.

## Capabilities and Constraints
24 lessons, 60 original problems, three paths; interactive notebooks, twelve visualization families, progressive hints, Java/Python/C++ execution, notes, practice plans, progress, cohorts, LeetCode public profiles, administration. Original Java trie, greedy set cover, randomized Quickselect; correctness tests and benchmarks. Gemini AI Studio free-tier key configured locally. External execution requires Judge0 credentials. Native and imported progress remain distinct.

## Brand Commitments
Name: 1on1. Interactive study notebook structure approved. Geist Sans with JetBrains Mono, neutral surfaces and cobalt accent, light/dark/system themes. Calm, precise, welcoming. No fabricated activity or unsupported mastery claims.

## Operating Context
Public GitHub repository: https://github.com/swarnimlovesyou/1on1. Local and containerized deployment, individually attributable commits, reproducible academic evidence.

## Product Principles
Understand before memorizing. Experiments show the real computed steps. Keep study context when moving into practice. Save work reliably. Explain failures and offer recovery.

## Accessibility & Inclusion
Keyboard-operable controls, visible focus, reduced motion, accessible static trace descriptions, responsive mobile layouts.
